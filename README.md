# Aaron J. Wilhelm — Personal Portfolio

A responsive, accessible personal portfolio website created for the Rutgers **Building Your Brand — Week 3 Portfolio Creation** assignment.

## Pages and content
- **Professional statement:** one-sentence introduction on the homepage.
- **Skills:** a clear list of supply chain, technical, and professional skills.
- **Projects:** three academic project/simulation case studies with working internal links.
- **Additional details:** experience, campus leadership, and contact links.

All three project summaries describe coursework or simulations, not employment deliverables. No confidential workplace material is published.

## Publishing using GitHub Pages
1. Open this repository on GitHub.
2. Choose **Settings → Pages**.
3. Under **Build and deployment**, set **Source: Deploy from a branch**.
4. Set **Branch: main** and **Folder: / (root)**, then click **Save**.
5. After deployment completes, visit:
   https://ajw267-dev.github.io/Aaron-Wilhelm-Portfolio-1/

## Files
- `index.html`: page and portfolio content.
- `styles.css`: typography, colors, layout, mobile styles.
- `script.js`: copyright year and active-navigation accessibility enhancement.
- `.nojekyll`: ensures GitHub Pages serves the site as-is.

There are no build dependencies. To preview locally, open `index.html` in a browser.
